# rs-value 0.8.0 Refactor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> `superpowers:executing-plans` to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking. Do not dispatch subagents for this
> workspace task.

**Goal:** Deliver the approved `rs-value 0.8.0` state, feature, JSON,
conversion, and API refactor, then migrate and verify `rs-config` and
`rs-metadata`.

**Architecture:** `qubit-datatype 0.6` remains the closed protocol authority;
one private `rs-value` type table supplies all mechanical mappings for the two
containers. Core storage and strict access remain available without default
features, rich storage is feature-gated, conversion is gated by `converter`,
natural JSON APIs require `converter` plus `json`, and downstream crates
consume `qubit-value/all`.

**Tech Stack:** Rust 2024, Cargo features, Serde, serde_json,
qubit-datatype 0.6, chrono, num-bigint, bigdecimal, url.

## Global Constraints

- Use crates.io `qubit-datatype = "0.6"`; do not use a path dependency.
- `default = []` and `all = ["converter", "chrono", "big-number", "url", "json"]`.
- Preserve `NamedValue` and `NamedMultiValues`.
- Directly remove all 189 redundant typed setter/adder methods in 0.8.0.
- Do not add, commit, or push Git changes.
- Preserve pre-existing uncommitted changes and edit only approved scope.
- Tests live under `tests/`; do not add inline `#[cfg(test)]` modules.
- Every behavior change follows red-green-refactor.
